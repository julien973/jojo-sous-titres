# sources/ — zone de dépôt

Dépose ici les fichiers à traiter (sous-titres FR à traduire, ou EN déjà traduits pour archivage direct).

## Comment déposer

1. Ouvre https://github.com/julien973/jojo-sous-titres/upload/main
2. Glisse le fichier .ass dedans (pas besoin de le renommer — GitHub accepte l'extension .ass)
3. Dans le champ du nom de fichier, tape sources/ devant le nom (ex. sources/e11-fr.ass)
4. Clique sur « Commit changes »
5. Dis juste « c'est ajouté » dans le chat

## Ce qui se passe ensuite (automatique)

- Récupération du fichier via GitHub (aucune troncature, intégrité vérifiée)
- Traduction EN complète + vérifications (Whitesnake, karaoké verbatim, marges, crédit)
- Push du .ass anglais dans subs/ + mise à jour du site (index.html) dans un seul commit
- Suppression du fichier source d'ici — cette zone reste vide en temps normal

Le livrable vit uniquement sur https://julien973.github.io/jojo-sous-titres/ — jamais présenté en chat.
